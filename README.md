# Depense 💸

A simple and intuitive expense tracker for individuals and groups.

- **Frontend:** Next.js + Tailwind
- **Backend:** Express.js + Prisma + PostgreSQL
- **Features:**
  - Track personal expenses
  - Create groups & add shared expenses
  - Balance settlements with simplified debts
  - Record manual payments between users
